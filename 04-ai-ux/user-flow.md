## Entry point

**Signal type:** New message / transcript received

A support engineer tags a Slack #escalations thread `P0` or `P1`. That tag — not a PM opening Juno and clicking a button — is the intent signal, and it fires straight into the "Raw Input" column of the Juno dashboard (M1).


**What they see instantly**

"Juno is reading the thread…" status pill lands under the new card within ~1s of the tag firing. The Insights and PRD columns dim to ~40% so the PM reads "in progress," not "broken."


## The flow

1. 1. Hybrid RAG retrieval over the Notion strategy doc + Slack/Jira evidence (M3 KB), top-K = 10, reranked from top-20 via Cohere rerank-v3.
2. Comparison logic: does the escalation's pain point map to a clause in the strategy doc?
3. Dual-citation scoring: emit P0-P3 or notRecommended, requiring both a strategy-clause citation AND an evidence citation.
4. Confidence + evidence-floor check: confidence < 70% → escalate to PM; < 3 relevant chunks retrieved OR no strategy doc loaded → withhold the ranking entirely.
2. "Scanning strategy doc + evidence…" → "Cross-referencing thread against strategy pillars…" → "Scoring citations + drafting PRD section…"
3. Path A (strategy doc loaded, ≥3 relevant chunks) → grounded P0-P3 with dual citation.
Path B (strategy doc missing OR < 3 chunks) → Juno withholds the ranking, shows "Insufficient evidence to recommend priority" banner + nudge to load the strategy doc or escalate to PM judgement.

## AI moments

**Placement:** Inline & Embedded

Each Insight Card in column 2 shows: a P0-P3 (or notRecommended) badge, a confidence score, and a two-part citation footer — one link to the strategy clause, one link to the evidence (Slack permalink or Jira ticket ID). Cards below 70% confidence are visually flagged "needs PM review." The PRD draft in column 3 references cards by the same citation footnotes.

Value prop = augmentation (M2). The PM is the validator — they check a citation against the source thread and edit or approve, they don't draft from blank. Inline placement keeps the raw Slack thread visible on the left so that check costs one glance, not a tab switch.

## Fallbacks

**Kill switch**

Every Insight Card has a "Manual Override" button → re-tag P0-P3, edit either half of the citation pair (strategy clause or evidence), or mark notRecommended. PRD blocks stay individually editable + regenerable — no forced approve-all-or-nothing. This kill switch covers every ranking Juno produces, confidence ≥70% or not.

**Training signal**

Manual override → logged as "strategic-alignment correction," tagged with which half of the citation pair the PM disagreed with (strategy clause or evidence). 3+ corrections against the same strategy clause → flag that clause as ambiguous and tighten retrieval around it (top-K, chunk boundaries), rather than let Juno keep citing a clause PMs have stopped trusting.

**Fail-safe**

If retrieval returns fewer than 3 relevant chunks (below M3's top-K=10 target) or no strategy doc is loaded, Juno never invents a citation pair. The card is tagged "Insufficient evidence" with an amber warning and no confidence score shown — the same evidence-floor + confidence<70% rule from the M3 PRD, not a new one invented here. PM can load the strategy doc, broaden the query, or promote the card manually with their own citation. No card is ever left in a P0-P3 state with no working next action.
